# Magic Cleaning

Professional house & office cleaning website for Cambridgeshire and Huntingdonshire.

## Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion**

## Develop

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
cd web
npm run build
npm start
```
